# Retail Sales Analytics Dashboard (Power BI)

## Overview
This project analyzes retail sales data to identify key trends, top-performing products, and customer behavior.

## Tools Used
- Power BI
- Excel

## Key KPIs
- Total Revenue
- Top Products
- Sales Trends
- Customer Segments

## Key Insights
- A small group of products contributes to a major share of revenue
- Seasonal trends impact overall sales performance
- Certain categories show higher return rates

## Features
- Interactive dashboard with slicers
- KPI cards for quick overview
- Visual analysis of sales and trends

## Files Included
- Power BI Dashboard (.pbix)
- Dataset (.xlsx/.csv)
- Dashboard screenshots
